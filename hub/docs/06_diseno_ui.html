Diseño UI — Sistema CSAT

Estado: PENDIENTE
Fecha: 13/08/2026
Fase actual: No iniciado

1. Propósito

Este documento contendrá los lineamientos de diseño visual de la interfaz una vez que exista una definición UI aprobada.

Actualmente el proyecto se encuentra en etapa de:

  • relevamiento funcional;
  • arquitectura de información;
  • UX;
  • wireframe de baja fidelidad.

Por lo tanto, no existe todavía diseño UI definitivo.

2. Lo disponible actualmente

Existe un wireframe navegable en blanco y negro.

Su objetivo es validar:

  • estructura;
  • jerarquía;
  • navegación;
  • formularios;
  • estados;
  • permisos;
  • acciones.

El wireframe no debe interpretarse como propuesta visual final.

3. Pendientes para iniciar UI

  • identificar design system existente de Correo Argentino;
  • definir si debe integrarse con un sistema visual corporativo;
  • tipografía;
  • paleta;
  • iconografía;
  • grid;
  • spacing;
  • elevación;
  • radios;
  • densidad;
  • componentes;
  • responsive;
  • accesibilidad;
  • estados de interacción.
